PhonePe Payment Insights Dashboard
📌 Project Overview
This project features an interactive Power BI dashboard designed to analyze digital payment transactions across India using PhonePe data. The objective is to uncover patterns in user behavior, transaction success rates, and demographic trends to deliver actionable business insights.

📊 Key Insights & Findings
Transaction Volume & Success: Analyzed 48,000 total transactions, recording a successful transaction volume of 11.58K.

Demographic Drivers: Gen X (37.4%) and Millennials (37.3%) represent the primary demographic groups driving digital payment adoption.

Service Usage: The "Loans" category dominates overall transaction value, showing peak activity on weekdays.

Behavioral Trends: Distinct usage patterns emerge between weekday and weekend activities, highlighting clear transaction peak windows.

🛠️ Tools & Technologies
Power BI: Interactive data visualization and dashboard design.

DAX (Data Analysis Expressions): Custom measures for metrics like Success Rate and Total Transaction Value.

Data Modeling: Relationship mapping and schema design across multiple data tables.

Data Transformation: Data cleaning and preprocessing to ensure analytical accuracy.
